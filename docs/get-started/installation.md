# Installation

Porter installs like any other Craft plugin — via Composer or directly from the Plugin Store.

## Composer

```sh
composer require bymayo/porter
```

Then enable the plugin:

```sh
php craft plugin/install porter
```

Or enable it in the control panel under **Settings → Plugins**.

## Plugin Store

In the control panel, go to **Plugin Store**, search for **Porter**, and click **Install**.

## Next steps

- Check the [Requirements](requirements.md) if the install fails.
- Every feature is off by default. Turn on what you need in [Setup](setup.md).
